# ForeverUI

Before working on the code, read [INDEX.md](INDEX.md): a map of every file, the module APIs, the schema format, the WotLK 3.3.5a / Lua 5.1 rules and how to run the tests. Update INDEX.md when the structure changes.

Every change is recorded in [CHANGELOG.md](CHANGELOG.md) under the top version (in Russian, grouped by module). A release gets a date and the next version number, and `## Version` in `ForeverUI.toc` moves with it.
